This lab note documents the architecture and steps taken to provision a secure VPC environment.

## Architecture Overview

- **Public Subnet:** Contains the NAT Gateway and bastion hosts.
- **Private Subnet:** Houses the application servers (EC2 instances) without direct internet access.
- **Security Groups:** Configured to strictly allow SSH access only from the bastion host.
